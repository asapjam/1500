NoSQL (Not only SQL) Instructions
---------------------------------------------------------------------------------------------------

General Goals
-------------
    Create a MongoDB Database within a Docker Container.
    The database should of course be non-relational (Not only SQL)


Materials
---------
    MongoDB Shell
    MongoDB Compass
    Docker Desktop

Installation
------------
    https://www.mongodb.com/docs/v7.0/tutorial/install-mongodb-community-with-docker/?msockid=0c8ec4d558cf6c3f3b82d25a59916d72

Mongo Terminal Commands
-----------------------
    launch terminal?
        mangosh

    use a database?
        use database_name

    build a "document"?
        document_name = {"key": "Value", "key": "Value", key: 0 };
        Ex.
            doc = {"title": "Tacos", "desc": "Yummy tacos", cook_time: 20 };
    
    insert a "document" into a database?
        db.category_name.insertOne(document_name)
        Ex.
            db.tacos.insertOne(doc)
        Note:
            Category doesn't have to exist yet, defining a new one here will create it.
    
    find()
    ------
    Description: Essentially a SELECT statement. It's aptly named.

    find all "document" contents?
        db.category_name.find().pretty();

    find a specific object?
        db.category_name.find({"key": "Value"}).pretty();
        Ex.
            db.category_name.find({"title": "Tacos"}).pretty();
    
    find objects that meet multiple criteria?
        db.category_name.find({"key": "Value"}, {"key2": "Value2"}).pretty();

    find and return only a specific part of an object?
        db.category_name.find({"key": "Value"}, {"key": 1}).pretty();
        Ex.
            db.category_name.find({"title": "Tacos"}, {"title": 1}).pretty();
    
    find and exclude only a specific part of an object?
        db.category_name.find({"key": "Value"}, {"key": 0}).pretty();
        Ex.
            db.category_name.find({"title": "Tacos"}, {"title": 0}).pretty();
    
     find and return only a specific part of ALL objects?
        db.category_name.find({}, {"key": 1}).pretty();
